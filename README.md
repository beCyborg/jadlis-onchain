# Вставь адрес кошелька — агент скажет, чей он, куда ушли деньги и что опасно

`jadlis-onchain` — скилл `/onchain` для Claude Code. Он разбирает адреса и транзакции в Tron
(TRX, USDT TRC-20) и в EVM-сетях: Ethereum, Polygon, Arbitrum, Base, Optimism, BSC.
Скилл только читает блокчейн. Подписать или отправить транзакцию он не может.

```
claude plugin install jadlis-onchain --marketplace https://github.com/beCyborg/jadlis-hub.git
```

Для Claude Code старше 2.1.292 — две команды:

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub.git
claude plugin install jadlis-onchain@jadlis
```

Это моё рабочее место, выложенное как есть, а не продукт.

## Что умеет

| Вопрос | Что делает скилл |
|---|---|
| Чей это адрес? | Собирает метки из четырёх источников: crypttrace (OFAC, ScamSniffer, кошельки бирж), Tronscan, сервис меток Blockscout, имя контракта из Etherscan. Метку подаёт как метку, а не как доказанного владельца. |
| Куда ушли деньги? | Трассирует USDT, а не только TRX или ETH. Сверяет с полным списком переводов: `crypttrace trace` показывает только три крупнейших выхода. |
| Есть ли среди получателей биржи? | Ищет депозитные адреса бирж: адрес за минуты пересылает всю сумму на помеченный кошелёк биржи. Для каждой строки пишет уровень доказательства. |
| Где живёт 0x-адрес? | Проверяет один адрес в девяти EVM-сетях: исходящие транзакции, баланс, токены. В сетях без бесплатной истории читает балансы USDC и USDT прямо из контрактов. |
| Связаны ли адреса? | Ищет прямые переводы и общих контрагентов. Для пары 0x/T проверяет, один ли это ключ. Обмены между сетями находит по времени и сумме и подаёт их как вывод. |
| Это безопасно? | Находит адреса-двойники (отравление адреса), безлимитные разрешения на списание USDT, заморозку USDT/USDC, спам-токены со ссылками. |

Что внутри:

- `skills/onchain/SKILL.md` — какой инструмент под какой вопрос, обязательные проверки, рецепты, формат ответа.
- `skills/onchain/scripts/api.sh` — шлюз к Etherscan V2, TronGrid, Tronscan, Blockscout и публичным RPC. Ключ подставляет сам и не печатает. Вызовы, которые подписывают или отправляют транзакцию, блокирует.
- `skills/onchain/references/` — справочники по официальной документации. Каждое утверждение в них проверено живым вызовом 09.11.2026. Там же — места, где crypttrace отвечает неверно.

## Как поставить

1. Поставь плагин командой выше.
2. Запусти установщик. Он ставит crypttrace через uv, обёртку для ключей и помощник `crypttrace-key`:

   ```
   bash "$(claude plugin list --json | jq -r '.[] | select(.id|startswith("jadlis-onchain@")) | .installPath')/scripts/setup.sh"
   ```

   Нужны `uv`, `jq`, `curl`, `python3`. Папка `~/.local/bin` должна быть в `PATH`. Состояние без изменений показывает тот же скрипт с флагом `--check`.
3. Заведи три бесплатных ключа. Каждый — почта и пароль, карта не нужна:
   - Etherscan: https://etherscan.io/register, потом https://etherscan.io/myapikey. Открывает историю в Ethereum, Polygon, Arbitrum, Linea и ещё 20 сетях.
   - Tronscan: https://tronscan.org/#/myaccount/apiKeys. Даёт метки и риск в Tron. Доступ без ключа Tronscan постепенно ограничивает.
   - TronGrid: https://www.trongrid.io/register, потом ключ в панели. Поднимает лимит запросов в Tron.
4. Скопируй каждый ключ и запусти `crypttrace-key etherscan`, `crypttrace-key tronscan`, `crypttrace-key trongrid`. Ключ уходит из буфера обмена в Связку ключей macOS. На экран выводится только его длина.

На Linux вместо шага 4 задай переменные `ETHERSCAN_API_KEY`, `TRONSCAN_API_KEY`, `TRONGRID_API_KEY`.

## Как пользоваться

Вставь адрес или хеш транзакции в Claude Code и задай вопрос. В примерах — публичные, широко известные адреса:

- `Проверь адрес TMuA6YqfCeX8EhbfYEg5y7S4DqzSJireY9: это биржа, что на нём лежит?` (холодный кошелёк биржи Binance в Tron, метка Tronscan «Binance-Cold 1»)
- `Чей адрес 0x098B716B8Aaf21512996dC57EB0615e2383E2f96 и под санкциями ли он?` (адрес взломщика моста Ronin в Ethereum, взлом 2022 года; адрес в санкционном списке OFAC США)
- `Куда ушли USDT с T…? Есть ли среди получателей биржи?` (вместо `T…` — любой адрес Tron)

Скилл сам выбирает сеть по виду адреса. Ответ начинается с вывода по каждому адресу. Потом идут таблица, потоки денег и ссылки на эксплореры. Факты и выводы помечены отдельно.

## Границы, стоимость, обновление

- Ключи бесплатные. Лимиты: Etherscan — 3 запроса в секунду и 100 000 в сутки, TronGrid с ключом — 100 000 в сутки.
- История переводов в Base, BSC, Avalanche и Gnosis на бесплатном уровне недоступна. Etherscan даёт её только по платному тарифу, а Blockscout для этих сетей закрыт от скриптов. Там скилл показывает только текущие балансы и прямо говорит, что история не проверена.
- Метка — это метка источника, а не доказанный владелец. Оценка риска 0 значит «нет известной плохой метки», а не «чисто».
- Скилл проверяли на macOS. На Linux нужен ручной шаг с переменными окружения.
- Обновления у получателей по умолчанию выключены. Обновить вручную:

  ```
  claude plugin update jadlis-onchain@jadlis
  ```

  Или включи автообновление один раз: `/plugin` → Marketplaces → jadlis.
